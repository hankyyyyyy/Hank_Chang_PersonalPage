1. 氣象署開放資料 API 規格 (F-C0032-001)

本專案使用中央氣象署「一般天氣預報-今明36小時天氣預報」資料集，涵蓋全台 22 縣市三階段時段預報：

  • Wx (Weather Phenomenon)：天氣現象文字及數值代碼（例如：晴天、多雲時晴、陰短暫陣雨）。
  • MaxT (Maximum Temperature)：預測最高溫度 (°C)。
  • MinT (Minimum Temperature)：預測最低溫度 (°C)。
  • PoP (Probability of Precipitation)：預測降雨機率 (%)。
  • CI (Comfort Index)：人體體感舒適度（如：舒適、悶熱、寒冷）。

2. 本地 SQLite 資料庫腳本 (遵循課綱流程)

已實作 weather_db.py，支援在終端機一鍵執行：

# 執行 Python 擷取氣象署資料並存入 SQLite
python weather_db.py

資料會自動格式化並持久化於 weather.db 的 weather_forecast 與 sync_logs 表格中。
